# 立项书 —「性格测试，看看你是哪种萌兽」

- 项目代号：mengshou-personality-test（萌兽测试）
- 立项日期：2026-11-08
- 负责人：piscon（产品）/ Muse（开发）
- 开发环境：Simular Box（代码资产以 GitHub 为准，防 Box 重置）
- 一句话定位：三分钟、十道题，把你的性格测成一只毛茸茸的小动物。

## 1. 产品定义

面向全年龄用户的轻量趣味性格测试。用户回答 10 道四选一情景题（约 3 分钟），系统按四维人格模型 + 分支亲和在本地即时计分，匹配 18 只「萌兽」之一，给出结果页（萌兽形象 + 性格解析 + 维度画像 + 匹配度 + 稀有度），并生成可分享的结果卡片，驱动社交传播。

- 目标用户：老少皆宜——以 18–35 岁、活跃于微信 / 小红书 / 朋友圈的测试爱好者为核心，题面场景（家庭、美食、旅行、朋友）对青少年与长辈同样友好
- 核心价值：好玩（萌兽形象）、有共鸣（文案写中自己）、可炫耀（分享卡片）
- 变现设想（后置）：激励广告解锁深度报告、付费定制结果卡、品牌联名题包；MVP 不做变现

## 2. 核心流程

首页（一句话钩子 + 开始按钮 + 萌兽图鉴预览）
→ 答题页（10 题，进度条，每题 4 个分支选项，大按钮，选完自动下一题，可回退）
→ 结果页（萌兽 + 匹配度 + 四维图 + 解析 + 小缺点 + 座右铭 + 最佳拍档）
→ 分享（生成海报图 / 复制结果文案）→ 朋友扫码再测，形成回流

设计原则：免登录、即时出结果、全部计算在本地完成（借鉴同类爆款产品的通行做法），首屏到结果不超过 3 分钟。

## 3. 内容模型（本项目原创的部分）

### 3.1 四个维度（借人格测评的二分维度结构，命名与文案原创）

| 维度 | 两极 | 考察题 |
|---|---|---|
| 社交能量 social | E 热力外向 / I 柔静内向 | Q1、Q2、Q9 |
| 决策方式 decision | T 理性分析 / F 情感直觉 | Q3、Q4、Q10 |
| 生活节奏 rhythm | J 计划有序 / P 随性自由 | Q5、Q6、Q10 |
| 行动态度 action | N 探索冒险 / S 稳妥守护 | Q7、Q8、Q9 |

### 3.2 题库

10 道情景题、每题 4 个选项（见 `data/questions.json`）。每个选项同时携带「维度极 + 萌兽亲和」双重计分：同维度的两个极各有两个选项，用不同生活气味区分（如同样是外向，「约朋友热闹」偏柴犬/水獭、「逛集市看新鲜」偏小猴/海豚），这就是分支选项——选的不只是极性，还有通往具体萌兽的小路。Q9、Q10 为双维度分支题，四个选项正好对应四种维度组合。题面全部取全年龄场景（周末、聚会、送礼、旅行、房间、新店、信条、朋友印象），不用职场/恋爱等限定人群的语境。题目、选项文案全部原创，不使用 MBTI 等受版权保护的原题。

### 3.4 计分算法（确定性、可解释）

借鉴「先建结果与维度、再出情景题、确定性计分」的方法论，引擎 v2 为两层计分：维度层（80 分）——每题选项给维度极记分 → 每维算出用户主导极与占比 → 萌兽按签名对齐度得分；分支亲和层（20 分）——每个选项携带 affinity，把具体选择导向具体萌兽，同签名萌兽（柴犬/企鹅、熊猫/考拉）靠亲和层分流。总分最高者为结果，平局依次按亲和点、签名距离裁定。引擎为框架无关的纯函数（`core/scoring.js`），已通过自测：18 只萌兽的典型画像 18/18 全部命中（含两对同签名分流），2000 次随机作答 18 只全部可达。

## 4. 技术选型（全端）

| 层 | 选型 | 理由 |
|---|---|---|
| 多端前端 | uni-app（Vue 3 + TypeScript） | 一套代码编译到微信/支付宝/抖音小程序 + H5 + App，国产多端事实标准，不重复造轮子 |
| UI 组件 | uni-ui（官方）+ 按需 uView Plus | 官方组件库，跨端兼容最稳 |
| 状态 | Pinia | uni-app Vue3 生态标配 |
| 计分引擎 | 自研纯函数 `core/scoring.js`（本仓库） | 框架无关，各端共用一份逻辑、一份数据 |
| 后端 | MVP 零后端；二期 uniCloud | 计分纯本地，MVP 不需要服务器；二期做结果统计/稀有度真实数据时用 uniCloud 免运维，后期量大再迁 Node + Express（可参考开源答题项目的服务端结构） |
| 分享海报 | Canvas 绘制（小程序端用 l-painter 类插件） | 跨端海报生成是成熟轮子，不手写 |
| 素材 | MVP：Twemoji 动物 SVG（CC BY 4.0，署名即可）+ 系统 emoji 兜底；二期：定制插画替换 | 避开 OpenMoji 的 CC BY-SA 传染性授权；详见 `docs/复用清单.md` |
| 工程 | Git + GitHub（资产主仓）+ H5 静态部署（GitHub Pages 起步） | Box 只是开发机，GitHub 是资产源头，防重置 |

仓库结构：

```
data/        题目与萌兽数据（JSON，各端共用）
core/        计分引擎 + 自测（框架无关）
prototype/   零依赖 H5 原型（立项验证用，直接引用 data/ 与 core/）
app/         uni-app 正式工程（M1 用官方预设脚手架生成，见 app/README.md）
docs/        立项书、复用清单
```

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| Box 突然重置丢代码 | 所有资产入 GitHub；Box 恢复后 `git clone` 即可还原（本次已验证 Box 的 git/网络可用） |
| 微信小程序审核：占卜/算命类目敏感 | 全程定位「娱乐趣味性格测试」，文案避开占卜、命运、预测类词，结果页带「仅供娱乐」声明 |
| 素材授权纠纷 | 只用 CC BY 4.0 / MIT / Apache 素材并保留署名文件（NOTICE.md）；自研文案与题目 |
| 题目被指抄袭 MBTI | 只借维度结构（不受版权保护的思想），题目与结果文案 100% 原创 |
| 结果分布失衡（人人同一只） | 计分自测含 500 次随机分布检查；上线后用真实数据回调稀有度与题目权重 |
